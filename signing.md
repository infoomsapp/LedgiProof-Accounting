\# LedgiProof — Code Signing Guide\*\*Olympus Mont Systems LLC\*\*\---\## Why sign?Without a code signing certificate:\- \*\*Windows\*\*: SmartScreen shows "Unknown publisher — do you want to run this?" and many users click away\- \*\*macOS\*\*: Gatekeeper blocks the app entirely — users must right-click → Open\- \*\*Both\*\*: Antivirus tools flag unsigned installers as suspiciousSigned apps install silently and build trust with clients.\---\## Windows — Code Signing\### Option A: Self-signed (development only — free)Use for internal testing only. Windows still shows a warning but will allow install.```powershell\\\\# Generate a self-signed cert (PowerShell as Admin)New-SelfSignedCertificate `\\\&#x20; -Subject "CN=Olympus Mont Systems LLC" `\\\&#x20; -Type CodeSigning `\\\&#x20; -CertStoreLocation Cert:\\\\\\\\CurrentUser\\\\\\\\My `\\\&#x20; -FriendlyName "LedgiProof Dev"\\\\# Export to PFX$cert = Get-ChildItem Cert:\\\\\\\\CurrentUser\\\\\\\\My | Where-Object { $\\\\\\\_.Subject -like "\\\\\\\*Olympus Mont\\\\\\\*" }Export-PfxCertificate -Cert $cert -FilePath build/ledgiproof-dev.pfx -Password (ConvertTo-SecureString "yourpassword" -AsPlainText -Force)```Then set in `.env`:```CSC\\\\\\\_LINK=build/ledgiproof-dev.pfxCSC\\\\\\\_KEY\\\\\\\_PASSWORD=yourpassword```\### Option B: EV Certificate (production — trusted immediately)Removes ALL SmartScreen warnings. Required for silent enterprise installs.\*\*Recommended providers:\*\*\- \*\*DigiCert EV Code Signing\*\* — \~$499/year, fastest trust build\- \*\*Sectigo EV Code Signing\*\* — \~$299/year, widely trusted\- \*\*SSL.com EV Code Signing\*\* — \~$249/year\*\*Process:\*\*1\. Purchase EV cert (requires business verification — 1-3 business days)2\. You receive a USB hardware token (required by Microsoft for EV)3\. Export `.pfx` from the token using DigiCert KeyLocker or similar4\. Set env vars:```env\\\\# .env (never commit)CSC\\\\\\\_LINK=C:/path/to/certificate.pfxCSC\\\\\\\_KEY\\\\\\\_PASSWORD=your-pfx-password```5\. Build:```powershellnpm run release:win```\### Option C: Azure Trusted Signing (cloud — no USB token)Microsoft's new cloud signing service. $9.99/month.```powershell\\\\# Install Azure CLIaz loginaz account set --subscription "your-subscription-id"```Set in `.env`:```AZURE\\\\\\\_KEY\\\\\\\_VAULT\\\\\\\_URI=https://your-vault.vault.azure.netAZURE\\\\\\\_CLIENT\\\\\\\_ID=your-client-idAZURE\\\\\\\_CLIENT\\\\\\\_SECRET=your-client-secretAZURE\\\\\\\_TENANT\\\\\\\_ID=your-tenant-idAZURE\\\\\\\_CERT\\\\\\\_NAME=ledgiproof-signing```Add to `electron-builder.yml`:```yamlwin:\\\&#x20; azureSignOptions:\\\&#x20;   endpoint: https://eus.codesigning.azure.net\\\&#x20;   codeSigningAccountName: your-account\\\&#x20;   certificateProfileName: ledgiproof-signing```\---\## macOS — Code Signing + NotarizationRequired for distribution outside the App Store on macOS 10.15+.\### Prerequisites\- Apple Developer Program membership ($99/year)\- Apple ID enrolled in the program\- Xcode Command Line Tools installed\### Setup```bash\\\\# List available signing identitiessecurity find-identity -v -p codesigning\\\\# You should see something like:\\\\# "Developer ID Application: Olympus Mont Systems LLC (XXXXXXXXXX)"```Set in `.env`:```envAPPLE\\\\\\\_ID=your@appleid.comAPPLE\\\\\\\_ID\\\\\\\_PASSWORD=xxxx-xxxx-xxxx-xxxx   # App-specific password from appleid.apple.comAPPLE\\\\\\\_TEAM\\\\\\\_ID=XXXXXXXXXX                # Your 10-char Team IDCSC\\\\\\\_NAME="Developer ID Application: Olympus Mont Systems LLC"```Enable notarization in `electron-builder.yml`:```yamlmac:\\\&#x20; hardenedRuntime: true\\\&#x20; gatekeeperAssess: false\\\&#x20; entitlements: build/entitlements.mac.plist\\\&#x20; entitlementsInherit: build/entitlements.mac.plist\\\&#x20; notarize:\\\&#x20;   teamId: XXXXXXXXXX```\### Build + notarize```bashnpm run release:mac\\\\# electron-builder signs + submits to Apple notarization automatically\\\\# Takes 2-10 minutes for Apple to respond```\---\## GitHub Actions — Automated SigningSigning in CI/CD. Never store certificates in the repo.\### Windows```yaml\\\\# .github/workflows/build.yml\\\\- name: Set up Windows signing\\\&#x20; env:\\\&#x20;   CSC\\\\\\\_LINK: ${{ secrets.WIN\\\\\\\_CERT\\\\\\\_BASE64 }}       # base64-encoded .pfx\\\&#x20;   CSC\\\\\\\_KEY\\\\\\\_PASSWORD: ${{ secrets.WIN\\\\\\\_CERT\\\\\\\_PASS }}\\\&#x20; run: npm run release:win```Encode your cert for GitHub Secrets:```powershell\\\\\\\[Convert]::ToBase64String(\\\\\\\[IO.File]::ReadAllBytes("cert.pfx")) | clip\\\\# Paste into GitHub → Settings → Secrets → WIN\\\\\\\_CERT\\\\\\\_BASE64```\### macOS```yaml\\\\- name: Set up macOS signing\\\&#x20; env:\\\&#x20;   CSC\\\\\\\_LINK: ${{ secrets.MAC\\\\\\\_CERT\\\\\\\_BASE64 }}\\\&#x20;   CSC\\\\\\\_KEY\\\\\\\_PASSWORD: ${{ secrets.MAC\\\\\\\_CERT\\\\\\\_PASS }}\\\&#x20;   APPLE\\\\\\\_ID: ${{ secrets.APPLE\\\\\\\_ID }}\\\&#x20;   APPLE\\\\\\\_ID\\\\\\\_PASSWORD: ${{ secrets.APPLE\\\\\\\_ID\\\\\\\_PASSWORD }}\\\&#x20;   APPLE\\\\\\\_TEAM\\\\\\\_ID: ${{ secrets.APPLE\\\\\\\_TEAM\\\\\\\_ID }}\\\&#x20; run: npm run release:mac```\---\## Minimum viable path (recommended)For the first public release of LedgiProof:1\. \*\*Today\*\* — release unsigned `.exe` to beta testers only.
